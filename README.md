# typing-speed-test
Typing speed test with WPM, accuracy tracking, and a clean UI. Built with HTML, CSS and JavaScript.

🔗 **Live demo:** https://crystal-khaing.github.io/typing-speed-test

## Features
- Random word generation
- Real-time WPM and accuracy tracking
- Light / dark mode toggle
- No frameworks, no dependencies

## Built with
- HTML5
- CSS3
- Vanilla JavaScript
